인턴십에서 읽을 논문, 미팅 기록, 공부한 내용을 한곳에 모아 두는 사이트입니다.
모든 내용은 GitHub 저장소 [lenyemu/internship](https://github.com/lenyemu/internship) 의 파일로 관리되고,
파일을 고치면 **1~2분 뒤 사이트에 자동으로 반영**됩니다. 따로 설치할 프로그램은 없습니다.

> 이 사이트는 **누구나 볼 수 있는 공개 웹사이트**입니다.
> 미발표 연구 아이디어, 데이터, 개인정보가 담긴 자료는 올리지 말고 Google Drive 등의 링크로 공유해 주세요.
> 논문 PDF도 저작권 문제가 있으니 arXiv · DOI 링크로 공유합니다.
{: .prompt-warning }

## 사이트 구성

| 메뉴 | 내용 | 수정하는 곳 |
|---|---|---|
| 논문 (첫 화면) | 주차별 논문 목록 | `_data/papers.yml` |

미팅 기록 · 노트 같은 글은 지금은 메뉴에 표시하지 않습니다. 논문 정리 글은 논문 표의 "정리 글" 칸에서 연결됩니다.

## 글 쓰는 법 (GitHub 웹에서)

1. 저장소의 [`_templates`](https://github.com/lenyemu/internship/tree/main/_templates) 폴더에서 쓰려는 글의 템플릿을 열고 내용을 복사합니다.
   - `meeting.md` : 미팅 기록
   - `note.md` : 이론 · 테크닉 노트
   - `paper.md` : 논문 정리
2. [`_posts`](https://github.com/lenyemu/internship/tree/main/_posts) 폴더로 가서 **Add file → Create new file** 을 누릅니다.
3. 파일 이름을 `YYYY-MM-DD-영문-제목.md` 형식으로 정합니다.
   - 예: `2026-11-13-weekly-meeting-2.md`, `2026-11-15-bayes-theorem.md`
   - 파일 이름의 제목 부분이 글 주소가 되므로 **영어 소문자, 숫자, `-`** 만 쓰는 것을 권장합니다.
4. 복사한 템플릿을 붙여넣고, 맨 위 `---` 사이의 머리말(제목, 카테고리 등)과 본문을 고칩니다.
5. **Commit changes** 를 누르면 끝입니다.
6. 1~2분 뒤 사이트를 새로고침하면 글이 보입니다.
   진행 상황은 저장소의 [Actions](https://github.com/lenyemu/internship/actions) 탭에서 볼 수 있습니다.
   (초록 체크 = 반영 완료, 빨간 X = 오류)

마크다운, 수식, 코드 블록 쓰는 법은 [글쓰기 문법 정리]({% link _posts/2026-11-06-writing-guide.md %}) 에 정리해 두었습니다.

> **처음 글을 쓰는 분**은 [`_data/authors.yml`](https://github.com/lenyemu/internship/blob/main/_data/authors.yml) 에 자신의 이름을 먼저 등록하고,
> 글 머리말의 `author:` 에 등록한 아이디를 적어 주세요.
{: .prompt-tip }

## 미팅 자료(파일) 올리는 법

1. 저장소의 `assets/files/meetings/` 폴더로 이동합니다.
2. **Add file → Upload files** 로 파일을 끌어다 놓고 **Commit changes** 를 누릅니다.
   - 파일 이름은 `2026-11-13-honggildong-slides.pdf` 처럼 **날짜-이름-내용**, 영문으로 짓고 공백은 피해 주세요.
   - 웹에서 한 번에 올릴 수 있는 파일은 25MB까지입니다. 큰 파일은 Google Drive 링크로 공유해 주세요.
3. 미팅 글에서 파일을 링크합니다. 쓰는 법은 [글쓰기 문법 정리 → 파일 첨부]({% link _posts/2026-11-06-writing-guide.md %}#파일-첨부) 를 참고하세요.

## 읽을 논문 목록 고치는 법

[`_data/papers.yml`](https://github.com/lenyemu/internship/blob/main/_data/papers.yml) 을 열고 연필 아이콘(Edit)을 눌러 수정합니다.
파일 맨 위에 각 항목의 의미가 적혀 있습니다. 들여쓰기는 **스페이스 2칸**이며, 탭 문자는 쓰면 안 됩니다.

## 사이트가 바뀌지 않을 때

[Actions](https://github.com/lenyemu/internship/actions) 탭에서 빨간 X가 붙은 항목을 눌러 오류 메시지를 확인합니다. 흔한 원인은 다음과 같습니다.

- **머리말 문법 오류**: 제목에 `:` 나 `#` 가 들어가면 `title: "제목: 부제"` 처럼 큰따옴표로 감싸야 합니다.
- **없는 파일로 가는 링크**: 파일 이름 오타, 또는 파일을 아직 올리지 않은 경우.
- **미래 날짜**: 파일 이름의 날짜가 오늘보다 뒤면 그 날짜가 될 때까지 글이 보이지 않습니다.

## 글쓰기 권한

저장소에 직접 글을 쓰려면 관리자가 **Settings → Collaborators** 에서 GitHub 계정을 초대해야 합니다.
초대받지 않은 경우에는 저장소를 Fork 해서 수정한 뒤 Pull Request 를 보내면 됩니다.
